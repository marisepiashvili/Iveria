# ივერია — გაზეთის ციფრული არქივი

სტატიკური საიტი „ივერიის“ ნომრების ტექსტისთვის, 1877 წლის გაზეთის იერსახით.
სერვერი და მონაცემთა ბაზა საჭირო არ არის — მუშაობს ნებისმიერ ჰოსტინგზე (GitHub Pages, Netlify…)
და კომპიუტერზეც, `index.html`-ის გახსნით.

## მთავარი გვერდი

`index.html` არის ლენდინგი ქაღალდიდან ამოჭრილი სტამბის სტილში: მთავარი სცენაა `assets/printshop.jpg`, მის ზემოთ დევს
ნაბეჭდი ფურცელი. ქვემოთ არის დაზგის ბორბლები, რომლებიც გადახვევისას ტრიალებს, ასოთა კასა, რომლითაც სიტყვა იკრიბება და
არქივში იძებნება, და წლების უჯრები. წლები და ნომრების რაოდენობა `data/`-დან იკითხება, ასე რომ აწყობის
შემდეგ თავისით ახლდება. პროგრამის ციტატა, ამონაბეჭდის ცხრილი და ფეხის ტექსტი `index.html`-ში იცვლება;
უჯრების ბოლო წელი (1906) `landing.js`-ის თავშია.

## ვის შეუძლია რედაქტირება

„ახალი ნომერი“, „რედაქტირება“ და „ინსტრუქცია“ ჩანს მხოლოდ მაშინ, როცა საიტს საკუთარ კომპიუტერზე ხსნით
(`index.html` ან `localhost`). ინტერნეტში ატვირთულ საიტზე მნახველები ხედავენ მხოლოდ არქივს, ძიებას და ნომრებს.

საიტის შეცვლა სხვას საერთოდ არ შეუძლია: ნომერი ქვეყნდება მხოლოდ მაშინ, როცა თქვენ ჩადებთ `.txt` ფაილს
`issues/`-ში და ატვირთავთ საქაღალდეს ჰოსტინგზე. ამიტომ ჰოსტინგის (GitHub, Netlify…) პაროლი მხოლოდ თქვენ უნდა იცოდეთ.

## კითხვის რეჟიმი

ნომრის გვერდზე მკითხველს შეუძლია აირჩიოს „გადახვევა“ (ყველა გვერდი ერთმანეთის ქვეშ) ან „ფურცვლა“
(ერთი გვერდი, გადაბრუნების ანიმაციით). ფურცვლისას გვერდი ბრუნდება ქვედა ღილაკებით, გვერდის კუთხეზე
დაწკაპუნებით, კლავიატურის ← → ისრებით ან ტელეფონზე თითის გასმით. არჩევანი ბრაუზერს ახსოვს.

## ახალი ნომრის დამატება

1. საიტზე გახსენით „ახალი ნომერი“, შეავსეთ ნომერი, თარიღი და ტექსტი. შენახვამდე შეგიძლიათ „გადახედვა“-ზე ნახოთ, როგორ გამოჩნდება.
   „მონახაზად შენახვა“ სამუშაოს ინახავს ამავე ბრაუზერში.
2. დააჭირეთ „ჩამოტვირთვა .txt“ და ფაილი ჩადეთ `issues/<წელი>/` საქაღალდეში.
   (ფაილის დაწერა სხვა პროგრამაშიც შეიძლება, ოღონდ UTF-8 კოდირებით.)
3. ორჯერ დააწკაპუნეთ `build.command`-ზე (Mac) ან `build.bat`-ზე (Windows).
   Mac-მა პირველად შეიძლება გაშვება დაბლოკოს: მაშინ მარჯვენა ღილაკი → „Open“.
   სკრიპტი გეტყვით, თუ რომელიმე ფაილში შეცდომაა (მაგ. არასწორი თარიღი ან გამეორებული ნომერი).
4. ატვირთეთ მთელი საქაღალდე ჰოსტინგზე (ან მხოლოდ შეცვლილი `issues/` და `data/`).

არსებული ნომრის გასწორება: ნომრის გვერდზე „რედაქტირება“ → „ჩამოტვირთვა .txt“ → ძველი ფაილის ჩანაცვლება → აწყობა.

## რატომ არ შენელდება საიტი

- მთავარი გვერდი ტვირთავს მხოლოდ წლების სიას, წლის გვერდი — მხოლოდ ერთი წლის კატალოგს,
  ნომრის გვერდი — მხოლოდ ერთი ნომრის ტექსტს.
- ძიება იყენებს წინასწარ აწყობილ ინდექსს, რომელიც პატარა ნაწილებადაა დაყოფილი:
  ერთი სიტყვის საძებნად იტვირთება რამდენიმე კილობაიტი და არა მთელი არქივი.
  სიტყვის ფორმებსაც პოულობს („ჩვეულება“ → „ჩვეულების“, „ჩვეულებას“); რამდენიმე სიტყვის შემთხვევაში
  აჩვენებს ნომრებს, სადაც ყველა სიტყვაა.
- შემოწმებულია 3000 ხელოვნურ ნომერზე: აწყობა ~16 წამი, ძიება ~40 მილიწამი.

## კომპიუტერზე გაშვება

`index.html` შეგიძლიათ პირდაპირ გახსნათ ბრაუზერში, ან:

```
python3 -m http.server 8377
```

და გახსენით http://localhost:8377
